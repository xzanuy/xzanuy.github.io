# Self-hosted fonts

Downloaded from the official Google Fonts distribution. Both families are licensed under the SIL Open Font License 1.1; their complete licenses are included alongside the font files.

- `manrope-latin.woff2`: Manrope, Latin subset, normal style, variable weight 200–800.
  Source: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSvfedN4.woff2
  License: `manrope-OFL.txt`, from https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt
- `instrument-serif-latin-italic.woff2`: Instrument Serif, Latin subset, italic style, weight 400.
  Source: https://fonts.gstatic.com/s/instrumentserif/v5/jizHRFtNs2ka5fXjeivQ4LroWlx-6zAjjH7Motmp5g.woff2
  License: `instrument-serif-OFL.txt`, from https://github.com/google/fonts/blob/main/ofl/instrumentserif/OFL.txt

The Latin subsets include the accented characters required for Spanish and Catalan.
